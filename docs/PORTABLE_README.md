# Codex 余额助手 v0.2.6

Windows x64 透明桌面宠物，用于显示本机 Codex 当前项目、任务进度、Token 消耗与用量窗口余额。

## 使用方法

1. 完整解压下载的 ZIP。
2. 保留本目录中的 `resources`、DLL、PAK、DAT 和 BIN 文件。
3. 双击 `Codex余额助手.exe`。
4. 打开 Codex 并选择一个本地项目。

请勿只移动 EXE；Electron 运行所需文件必须和 EXE 保持当前目录结构。

## 系统要求

- Windows 10/11 x64
- 本机已经使用过 Codex，并存在本地会话状态

当前 EXE 未进行商业代码签名，Windows SmartScreen 可能显示“未知发布者”。请确认文件来自项目官方 GitHub Release 后，再选择“更多信息 → 仍要运行”。

## 数据与隐私

- 只读扫描本机 Codex 状态和会话日志。
- 不读取或展示提示词正文。
- 不上传项目内容、账号信息或日志。
- 不修改 Codex 配置、账号和会话文件。

窗口余额来自 Codex 日志中的用量窗口百分比，不是现金余额或 API 账单金额。
