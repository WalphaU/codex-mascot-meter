## 从 v0.2.6 到 v0.4.0

这次把原来的「Codex 余额助手」升级成了「Codex 余额 Plus（社区版）」。原有的项目跟随、Token 统计和每日/分时图表都还在，主要补上了动态桌宠、双窗口额度和更紧凑的面板。

### 桌宠动起来了

原来只有精简桌宠和详细面板，现在多了一个只显示人物的动态模式。待机时会轻轻呼吸、眨眼，发梢也会跟随；点击会点头回应，拖起来会播放揪住后衣领的挣扎动画，松手后有落地缓冲。也可以聚焦人物后按 Enter 或空格互动。

待机使用 Canvas 2D 连续补间，6.4 秒一轮，脚底保持固定。当前版本保持安静待机，不会定时随机走动、睡觉或传送。

### 额度更完整，面板更省地方

- 原来界面主要展示一个额度窗口，现在精简模式和详细面板都能同时查看 5 小时与周额度，详细面板分别显示重置倒计时。
- 低额度提醒从「主窗口剩余不超过 20%」调整为「任一窗口剩余不超过 10%」，周额度偏低也能提醒。
- 详细面板从 432×800 缩到 432×680 DIP，高度减少 15%。去掉「最近项目日志」列表，保留字号、Token 统计、缓存命中、趋势图和运行信息。

### 修正了这些显示和窗口问题

- 补充读取 Codex 的设置更新事件和 reasoning_effort 字段，减少模型与推理强度显示为空的情况。新会话尚未写入设置时，沿用当前项目最近一次有效配置。
- 任务进度与人物状态分开处理。额度偏低时，正在运行的任务仍会显示计划进度；没有计划时继续显示进行中 / LIVE。
- 从屏幕边缘的桌宠展开面板时，会把面板放回当前屏幕的可用区域，减少内容落在屏幕外的问题。
- 快速切换模式或在切换中开始拖拽时，会校正窗口尺寸，避免停留在不完整的过渡状态。

新增动态模式也做了交互保护：隐藏的拖拽层不会挡住原有按钮和图表；松开鼠标、失去焦点或取消捕获都会结束拖拽；连续点击不会重复重启动作。人物与返回按钮之间留有悬停区域，移过去时按钮不会立刻消失。

### 运行方面

动画素材随程序本地提供，没有增加 Live2D、Spine 等运行依赖。隐藏窗口、退出动态模式或开启「减少动态效果」后，会停止待机绘制；加载或绘制失败时回退静态人物，额度与进度面板仍可使用。

原版的增量日志读取、快照复用、IPC 去重和图表按需重绘继续保留。待机目标为 60 FPS，实际帧率取决于设备负载，本次不承诺统一的 CPU 或内存降幅。

### 下载与升级

退出旧版，下载并完整解压 `Codex-Meter-Plus-v0.4.0-windows-x64.zip`，运行 `Codex余额Plus.exe`。请保留整个文件夹，不要只移动 EXE；旧版目录可以留着，方便需要时切回去。

系统要求仍为 Windows 10/11 x64，本机已经使用过 Codex。应用尚未进行商业代码签名。
