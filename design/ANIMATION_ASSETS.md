# 动态桌宠序列素材说明

本文记录素材制作与分镜，供维护参考。v0.4.0 实际启用连续待机、点击回应、拖拽和落地；不启用下列历史设计中的随机动作。待机实现见 [待机素材说明](../src/assets/idle/README.md)。

运行素材位于 `src/assets/sequences/`。每个 WebP 是 4 列 × 2 行的 8 帧透明图集，单帧逻辑画布为 360 × 360，人物使用同一空间原点与地面基线。运行时只保留两个序列图层，动作完成后清除背景图引用。

## 生成方式

- 模式：Codex 内置 ImageGen。
- 身份主参考：`src/assets/mascot-dynamic-base.webp`。
- 动作参考：对应的 `src/assets/mascot-action-*.webp`。
- 共同提示约束：保持白发、青绿色眼睛、黑白水手服与青绿色饰边；输出 4 × 2、恰好 8 帧；从左到右、从上到下构成“预备—主体—惯性跟随—收势”；相机、人物比例、中心锚点和地面基线一致；背景使用纯洋红色供本地去底；禁止文字、编号、边框、额外角色和多余肢体。
- 分动作提示分别细化了左顾右盼、蹲跳腾空落地、完整步态、发现/咀嚼/吞咽/打嗝、举杯/饮用/满足、入睡/呼吸/梦中抽动、点头/惊醒、阅读/翻页、发呆摇摆、传送收缩/展开/落地。

## 构建方式

`scripts/build-sprite-atlas.py` 会切分 4 × 2 原图，去除洋红背景与边缘溢色，统一缩放，并在保留跳跃、下蹲和躺卧位移的前提下写入透明 WebP 图集。

示例：

```powershell
python scripts/build-sprite-atlas.py --input generated-look.png --output src/assets/sequences/mascot-sequence-look.webp
```

原始 ImageGen 输出保留在 Codex 的生成图目录中；项目发布和便携版只携带经过归一化的透明 WebP，避免把制作中间文件加入运行包。
